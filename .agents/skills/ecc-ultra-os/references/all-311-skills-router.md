# 🗂️ Полный Мастер-Индекс и Роутер Хранилища ECC Ultra OS (311 Скиллов + 71 Агент + 22 Пакета Правил + 97 Команд)

Этот документ — **единая карта навигации по 100% оригинальной и усиленной базе знаний ECC**, физически упакованной внутри вашего навыка в папке [`../vault/`](../vault/).

> **Почему это сделано именно так (Архитектура Zero-Bloat Vault):**
> Если положить 311 папок скиллов напрямую в глобальный корень `~/.gemini/config/skills/`, система будет инжектировать 311 описаний (~18 000 токенов) в системный промт на **каждом сообщении**. Вместо этого все **311 скиллов**, **71 агентов**, **22 языковых пакетов правил** и **97 команд** упакованы в единое хранилище `ecc-ultra-os/vault/`. В глобальном списке навыков они занимают **всего 1 слот**, а агент мгновенно подгружает нужный `SKILL.md` по ссылкам ниже или через скрипт `scripts/search-ecc-vault.ps1`!

## 📊 Сводная статистика хранилища `vault/`

| Компонент | Количество | Путь внутри навыка | Как использовать |
| :--- | :---: | :--- | :--- |
| **Skills (Навыки и Плейбуки)** | **311** | `vault/skills/<name>/SKILL.md` | Прочитать нужный `SKILL.md` (и его `references/` / `scripts/`) через `read_file` |
| **Agents (Субагенты)** | **71** | `vault/agents/<name>.md` | Использовать как системный промт для `define_subagent` / `invoke_subagent` |

| **Commands (Воркфлоу-команды)** | **97** | `vault/commands/<name>.md` | Шаблоны быстрых сценариев (`/plan`, `/tdd`, `/code-review`, `/e2e` и др.) |
| **Contexts (Режимы работы)** | **3** | `vault/contexts/{dev,research,review}.md` | Фокус-профили для разработки, исследования и ревью |

# Инженерный регламент проекта (ECC Ultra OS v3.0 Harness)

Данный проект функционирует под управлением инженерного харнеса **ECC Ultra OS v3.0** ([.agents/skills/ecc-ultra-os](.agents/skills/ecc-ultra-os/SKILL.md)).

## 1. Базовые принципы
- **GateGuard:** Перед созданием или изменением файлов обязательно проверять 4 факта: импортёры/точки вызова, публичный контракт, отсутствие дубликатов, схемы данных.
- **TDD:** Разработка критической логики через `Red -> Green -> Refactor` с целевым покрытием $\ge 80\%$.
- **Zero-Slop & Plankton Lock:** Запрещены заглушки (`// TODO`, пустые обработчики, фейковые массивы в проде). Категорически запрещено ослаблять конфиги линтеров/тайпчекеров (`tsconfig.json`, `eslint`, `ruff`) ради подавления ошибок.
- **Верификация:** Финальная сдача задач подтверждается через 6-фазный чеклист (`verify-6phase.ps1`): сборка, типы, линтер, тесты, безопасность/секреты AgentShield, git diff.
- **Роутер навыков и агентов:** Для подключения специализированных стеков (React, FastAPI, Docker, БД и др.) использовать встроенную базу из 311 скиллов через `.agents/skills/ecc-ultra-os/scripts/search-ecc-vault.ps1`.
